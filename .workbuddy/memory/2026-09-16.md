## 关键技术发现

1. **`04套环检测.hdev` 的 `threshold(192,255)` 选中的是背景不是零件**。
   素材 `图像00228/235.BMP` 是 800×600 灰度图，亮背景（≈255）占 92.5%、暗色挡圈（≈30）占 7.5%。
   算法原理：每个闭合挡圈的暗色环体把一小块亮背景围死 → `connection` 后这些"内孔"各自成为独立连通域 →
   **数内孔个数 = 数零件个数**。`select_shape` 的 `area ≤ 213574` 正是**踢掉外圈大背景**（实测约 41.2 万像素），
   `inner_radius ≥ 8.7` 则是"确认这是被围出来的内孔"的关键条件。
   实测复算：连通域 57 个 → area 过滤后 56 → 最终 **00228 保留 27 个 / 00235 保留 25 个**（内孔面积 816~995，直径 34.4~35.5）。
   局限：左上角那个**开口的 "C" 形挡圈**因环体不闭合，内孔与外背景连通 → 不会被计数。

2. **8bpp BMP 调色板偏移坑**：调色板起始 = `14 + BITMAPINFOHEADER 长度(54)`，
   写成常见的 `14 + 像素数据偏移 - 1024` 会得到错乱配色（黑底白图渲染成绿底）。已在 `bmp2png.py` 中修正。

3. **Obsidian 不支持 BMP 预览**，笔记要内嵌图片必须先转 PNG（`Halcon学习笔记/assets/`）。

4. **`orientation_region` 返回弧度**，官方 assertion 为 `-π <= Phi < π`；画主轴箭头终点 =
   `(Row - L*sin(Phi), Column + L*cos(Phi))`（Row 轴向下故取负），与官方 `clip.hdev` 一致。

5. **`circularity` ≠ `roundness`**：前者 `= min(1, Area/(max²·π))`（筛圆形斑点用这个）；后者基于
   `dist_mean`/`dist_deviation`，窄边圆环也会接近 1。
