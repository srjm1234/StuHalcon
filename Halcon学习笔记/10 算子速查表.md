## 五、分割与形态学

| 算子 | 说明 |
|---|---|
| `connection (Region, ConnectedRegions)` | 按**8 邻域**打散成连通域 |
| `dilation_circle (Region, Out, Radius)` | 膨胀（变胖） |
| `erosion_circle (Region, Out, Radius)` | 腐蚀（变瘦） |
| `opening_circle (Region, Out, Radius)` | **开运算**：先腐蚀后膨胀 → 去小白点/毛刺 |
| `closing_circle (Region, Out, Radius)` | **闭运算**：先膨胀后腐蚀 → 填小黑点/裂缝 |
| `dilation_rectangle1` / `erosion_rectangle1` / `opening_rectangle1` / `closing_rectangle1` | 矩形结构元版本 |
| `opening` / `closing` | 任意结构元版本 |
| `fill_up (Region, Out)` | 填充**所有**孔洞（不看孔大小） |
| `boundary (Region, Border, 'inner'\|'outer')` | 取边界 |
| `skeleton (Region, Skeleton)` | 取骨架（中轴） |
| `shape_trans (Region, Out, Type)` | `'convex'` 凸包 / `'ellipse'` 等效椭圆 / `'rectangle1'` / `'rectangle2'` |
| `distance_transform (Region : DistanceImage : Metric, Foreground, Width, Height)` | 距离变换：区域内（`'true'`）或区域外（`'false'`）每个点到边界的距离；`Metric` 可用 `'euclidean'`。**用来求缺陷内切圆半径 → 定形态学半径下限** |

> [!tip] 一句话口诀
> **开运算去"白"的小东西，闭运算去"黑"的小东西。**

> [!tip] `Radius` 怎么定？
> 圆盘结构元下，腐蚀/膨胀等价于**距离阈值**，所以
> **半径下限 = 缺陷的内切圆半径**（白斑到最近黑点的最大距离 / 孔洞到最近白点的最大距离），
> 用 `distance_transform` 在缺陷区域内取极大值即可得到；
> 实际贴着它向上取（`Radius` 是实数，不必凑整）。标定流程与实测数据见 [[13 形态学调整 结构元半径标定]]。

### 8.2 2D 计量（Metrology）

详见 [[15 测量模型 2D Metrology]]。五步：`create_metrology_model` → `set_metrology_model_image_size` → `add_metrology_object_*_measure` → `apply_metrology_model` → `get_metrology_object_result`。

| 算子 | 说明 |
|---|---|
| `create_metrology_model (MetrologyHandle)` | 创建计量模型（空壳） |
| `set_metrology_model_image_size (Handle, Width, Height)` | 告诉它图像尺寸（**应在 `add_*` 之前**） |
| `add_metrology_object_line_measure (Handle, RowBegin, ColBegin, RowEnd, ColEnd, MeasureLength1, MeasureLength2, MeasureSigma, MeasureThreshold, GenParamName, GenParamValue, Index)` | 加"找线"对象 |
| `add_metrology_object_circle_measure (Handle, Row, Column, Radius, ...)` | 加"找圆"对象 |
| `add_metrology_object_rectangle2_measure (Handle, Row, Column, Phi, Length1, Length2, ...)` | 加"找矩形"对象 |
| `add_metrology_object_ellipse_measure (Handle, Row, Column, Phi, Radius1, Radius2, ...)` | 加"找椭圆"对象 |
| `add_metrology_object_generic (Handle, Shape, ShapeParam, ...)` | 通用版，`Shape` = `'circle'`/`'ellipse'`/`'rectangle2'`/`'line'` |
| `set_metrology_object_param (Handle, Index, GenParamName, GenParamValue)` | 调卡尺（`Index` 可写 `'all'`） |
| `apply_metrology_model (Image, Handle)` | 执行测量 |
| `get_metrology_object_result (Handle, Index, Instance, 'result_type', 'all_param', Parameter)` | 取结果 |
| `get_metrology_object_result_contour (Contour, Handle, Index, Instance, Resolution)` | 取**拟合出来的**形状轮廓 |
| `get_metrology_object_model_contour (Contour, Handle, Index, Resolution)` | 取**你画的近似**形状轮廓 |
| `get_metrology_object_measures (Contours, Handle, Index, Transition, Row, Column)` | 取**卡尺矩形** + 实测边缘点 |
| `set_metrology_model_param (Handle, 'reference_system', [Row, Column, Angle])` | 定基准（**只在建模型时设一次**） |
| `align_metrology_model (Handle, Row, Column, Angle)` | 对齐到当前图的姿态（**每次测之前都要调，会被下次覆盖**） |
| `gen_cross_contour_xld (Cross, Row, Column, Size, Angle)` | 把边缘点画成十字叉 |

**`all_param` 输出顺序**：circle `[row, column, radius]`（3）／ line `[row_begin, column_begin, row_end, column_end]`（4）／ rectangle2 `[row, column, phi, length1, length2]`（5）／ ellipse `[row, column, phi, radius1, radius2]`（5）。

**关键参数默认值**：`MeasureLength1 = 20`（垂直于边界的半长 = **测量容差**）／ `MeasureLength2 = 5`（切向半长）／ `num_measures = 10`／ `num_instances = 1`／ `min_score = 0.7`／ `distance_threshold = 3.5`（RANSAC）。

> [!danger] 三条最容易踩的
> ① `num_measures` 与 `measure_distance` **互斥**（设了后者，前者失效）；卡尺数下限：圆 3 / 椭圆 5 / 直线 2 / 矩形每边 2。
> ② `all_param` 是**按"添加顺序 × 实例"拼的一维元组**，下标要自己算。
> ③ 三个 `get_*_contour` 含义不同：`model_contour` = 你画的近似形状，`measures` = 卡尺+边缘点，`result_contour` = 拟合结果。

## 九、仿射变换（`HomMat2D`）

详见 [[11 仿射变换矩阵与图像变换]]、[[12 仿射变换实战 区域轮廓与抠图]]。

> [!danger] 一句话铁律
> 齐次矩阵作用在图像数据上时，**行坐标传给 x、列坐标传给 y**，也就是**照常按 `(Row, Column)` 顺序写**。官方原文：`the order of passing row and column coordinates follows the usual order (Row, Column)`。正角度 = 屏幕上**逆时针**。

**矩阵的存储**：`HomMat2D` 是**长度 6 的实数元组** `[ra, rb, tc, rd, re, tf]`，对应
$\begin{bmatrix} ra & rb & tc\\ rd & re & tf\\ 0&0&1\end{bmatrix}$。

### 9.1 构造矩阵

| 算子 | 参数顺序 | 说明 |
|---|---|---|
| `hom_mat2d_identity (HomMat2DIdentity)` | 无 | 单位矩阵，手工拼装的起点（**必写**） |
| `hom_mat2d_rotate (HomMat2D, Phi, Px, Py, Out)` | 角度在前，`(Px,Py)` = 固定点 | 逆时针旋转 `Phi`（弧度） |
| `hom_mat2d_scale (HomMat2D, Sx, Sy, Px, Py, Out)` | 缩放在前，`(Px,Py)` = 固定点 | `Sx` 管行方向、`Sy` 管列方向 |
| `hom_mat2d_translate (HomMat2D, Tx, Ty, Out)` | 无固定点 | `Tx` 移行、`Ty` 移列 |
| `hom_mat2d_slant (HomMat2D, Theta, Axis, Px, Py, Out)` | `Axis` = `'x'`/`'y'` | 斜切；`'y'` 表示 y 轴斜切、x 轴不动 |
| `hom_mat2d_reflect (HomMat2D, Px, Py, Out)` | —— | 关于直线镜像 |
| `vector_angle_to_rigid (Row1, Col1, Ang1, Row2, Col2, Ang2, Out)` | 全为控制参数 | **点 + 角度对应 → 刚体矩阵**，最常用 |
| `vector_to_rigid` / `vector_to_similarity` / `vector_to_aniso` / `vector_to_hom_mat2d` | —— | 多组对应点反求矩阵（能力依次变强） |
| `hom_mat2d_invert (HomMat2D, Out)` | —— | 求逆（正变换 ↔ 反变换） |
| `hom_mat2d_to_affine_par (HomMat2D, Sx, Sy, Phi, Theta, Tx, Ty)` | 6 个输出 | **反解**变换参数 |

> [!tip] 叠加顺序
> `hom_mat2d_*` 是**左乘**：**代码里先写的操作，先作用在对象上**。
> 因此后面操作里的固定点 `(Px, Py)` 要写"**前面几步搬完之后**"的位置 —— 写"原始位置"就会跑偏。

### 9.2 用出去

| 算子 | 对象 | 控制参数 |
|---|---|---|
| `affine_trans_image (Image, Out : HM, Interpolation, AdaptImageSize)` | Image | 插值 `'nearest_neighbor'`/`'bilinear'`/`'constant'`(默认)/`'weighted'`/`'bicubic'`；尺寸 `'true'`/`'false'`（默认） |
| `affine_trans_region (Region, Out : HM, Interpolate)` | Region | `'nearest_neighbor'`(默认) / `'constant'` |
| `affine_trans_contour_xld (Contours, Out : HM)` | XLD 轮廓 | 无 |
| `affine_trans_polygon_xld (Polygons, Out : HM)` | XLD 多边形 | 无 |
| `affine_trans_pixel (HM, Row, Col, RowT, ColT)` | 点，**像素坐标系** | 传参 `(Row, Col)` |
| `affine_trans_point_2d (HM, Px, Py, Qx, Qy)` | 点，**标准坐标系** | 传参 `(Px, Py)` = `(Col, Row)` |

> [!warning] 三条容易踩的
> ① `affine_trans_image` **忽略输入图像的 domain**（当作整幅矩形），且**左、上边界永远会被裁掉**；
> ② `affine_trans_image` / `affine_trans_region` 用的是**像素坐标系**（原点在左上角像素外角），和 `area_center` 返回的标准坐标系差 **0.5 像素**；
> ③ `hom_mat2d_to_affine_par` 只认官方的拼装顺序 `scale → slant → rotate → translate`，顺序不同就反解不回原参数。

> [!note] 顺带记住这几个
> - `gen_contour_region_xld (Regions : Contours : Mode)`，`Mode` = `'border'`（默认）/ `'center'` / `'border_holes'`
> - `area_center_xld (XLD : : : Area, Row, Column, PointOrder)`，比区域版多一个绕行方向
> - `orientation_xld (XLD : : : Phi)`
> - `reduce_domain (Image, Region : ImageReduced)` —— 矩阵尺寸**不变**
> - `crop_domain (Image : ImagePart)` —— 矩阵裁到 domain 的最小外接矩形
> - `full_domain (Image : ImageFull)` —— 把 domain 扩回整块矩形

| `clear_shape_model (ModelID)` | —— | 释放句柄 |

**关键参数取值速记**

| 参数 | 取值 | 含义 |
|---|---|---|
| `Metric` | `'use_polarity'` / `'ignore_global_polarity'` / `'ignore_local_polarity'` / `'ignore_color_polarity'` | 对比度匹配规则；**前三种只用单通道（静默取第一通道）**，第四种支持多通道 |
| `SubPixel` | `'none'` / `'interpolation'`（推荐）/ `'least_squares'` / `'least_squares_high'` / `'least_squares_very_high'` / `['least_squares','max_deformation 2']` | 亚像素精度，`max_deformation` 取值 0~32 |
| `NumMatches` | `0` = 找全部 | `MinScore` 优先于它 |
| `Greediness` | `0` = 安全慢 / `1` = 快可能漏 | 抽稀模型点后降到 `0.7`~`0.8` |
| `MinScore` | 无遮挡可 `0.8`~`0.9` | 得分下限，越大越快 |
| `MaxOverlap` | 0~1，`0` = 互不重叠 | 模型有对称性时要调大 |
| `Contrast` | `'auto'` 或 $[下,上]$ 或 $[下,上,最小尺寸]$ | 滞后阈值，第三值按成分大小抑制小碎块 |
| `MinContrast` | `'auto'` 或数值 | 把模型与噪声分开 |

> [!danger] 三条最容易踩的
> ① 角度一律是**弧度**，写 `rad(180)` 不是 `180`；创建与查找的角度范围**必须有重叠**。
> ② 模型必须**完全落在图像内**才可能被找到；贴边也可能漏，需 `set_system ('border_shape_models','true')`。
> ③ `get_shape_model_contours` 的轮廓在 $(0,0)$，回显顺序必须是 **旋转（+缩放）→ 平移**，颠倒就飞出画面。
