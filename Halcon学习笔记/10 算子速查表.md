# 10 算子速查表

> [!abstract] 用法
> 按"我想做什么"查表。括号内为**参数顺序**，`:` 前面是输入输出图像/区域，后面是控制参数。
> 快捷键：光标停在算子上按 `F1` 打开官方帮助（**先看 Signature 定参数顺序，再看 Description 懂含义**）。

## 一、窗口与显示（`dev_` / `disp_` / `set_`）

| 算子 | 签名要点 | 说明 |
|---|---|---|
| `dev_close_window ()` | 无参 | 关闭当前图形窗口 |
| `dev_open_window (Row, Column, Width, Height, Background, WindowHandle)` | 全为控制参数 | 打开新窗口，左上角屏幕坐标 + 尺寸 + 底色 |

| `dev_display (Object)` | 图像 / 区域 / XLD | 显示对象 |

| `dev_set_colored (NumColors)` | 如 `12` | 用 N 色循环给多个区域上色 |
| `dev_set_draw ('fill' \| 'margin')` | `'fill'` 填充 / `'margin'` 只画轮廓 | 区域显示模式 |
| `dev_set_line_width (Width)` | 如 `3` | 线宽 |
| `dev_set_paint (...)` | —— | 更高级的绘制模式设置 |

| `disp_message (WindowHandle, String, CoordSystem, Row, Column, Color, Box)` | `Box` = `'true'`/`'false'` | 绘制文字（可传元组，自动逐个显示） |
| `disp_arrow (WindowHandle, Row1, Column1, Row2, Column2, Size)` | 起终点 + 箭头大小 | 画箭头 |

| `disp_cross (WindowHandle, Row, Column, Size, Angle)` | —— | 画十字 |
| `disp_line (WindowHandle, Row1, Column1, Row2, Column2)` | —— | 画线段 |
| `disp_rectangle1 (WindowHandle, Row1, Column1, Row2, Column2)` | —— | 画正矩形 |
| `disp_rectangle2 (WindowHandle, Row, Column, Phi, Len1, Len2)` | 中心 + 角度 + 半长半宽 | 画带角度矩形 |

> [!tip] `'image'` 与 `'window'` 坐标
> **标注目标用 `'image'`**（跟着图像走），**显示统计信息用 `'window'`**（固定在窗口某处）。

## 四、区域集合运算

| 算子 | 数学含义 | 记忆 |
|---|---|---|
| `intersection (R1, R2, Out)` | $R_1 \cap R_2$ | 共有部分 |
| `union1 (Regions, Out)` | 合并**一整组** | 一组变一个 |
| `union2 (R1, R2, Out)` | $R_1 \cup R_2$ | 两个变一个 |
| `difference (R1, R2, Out)` | $R_1 - R_2$ | **有方向！** R1 挖掉 R2 |
| `symm_difference (R1, R2, Out)` | $R_1 \oplus R_2$ | 异或，并集减交集 |
| `complement (R, Out)` | $\overline{R}$ | 相对**整幅图像**取反 |
| `concat_obj (Obj1, Obj2, Out)` | 拼接 | **不合并像素**，个数相加 |

## 九、仿射变换（`HomMat2D`）

详见 [[11 仿射变换矩阵与图像变换]]、[[12 仿射变换实战 区域轮廓与抠图]]。

> [!danger] 一句话铁律
> 齐次矩阵作用在图像数据上时，**行坐标传给 x、列坐标传给 y**，也就是**照常按 `(Row, Column)` 顺序写**。官方原文：`the order of passing row and column coordinates follows the usual order (Row, Column)`。正角度 = 屏幕上**逆时针**。

**矩阵的存储**：`HomMat2D` 是**长度 6 的实数元组** `[ra, rb, tc, rd, re, tf]`，对应
$\begin{bmatrix} ra & rb & tc\\ rd & re & tf\\ 0&0&1\end{bmatrix}$。

### 9.1 构造矩阵

| 算子 | 参数顺序 | 说明 |
|---|---|---|
| `hom_mat2d_identity (HomMat2DIdentity)` | 无 | 单位矩阵，手工拼装的起点（**必写**） |
| `hom_mat2d_rotate (HomMat2D, Phi, Px, Py, Out)` | 角度在前，`(Px,Py)` = 固定点 | 逆时针旋转 `Phi`（弧度） |
| `hom_mat2d_scale (HomMat2D, Sx, Sy, Px, Py, Out)` | 缩放在前，`(Px,Py)` = 固定点 | `Sx` 管行方向、`Sy` 管列方向 |
| `hom_mat2d_translate (HomMat2D, Tx, Ty, Out)` | 无固定点 | `Tx` 移行、`Ty` 移列 |
| `hom_mat2d_slant (HomMat2D, Theta, Axis, Px, Py, Out)` | `Axis` = `'x'`/`'y'` | 斜切；`'y'` 表示 y 轴斜切、x 轴不动 |
| `hom_mat2d_reflect (HomMat2D, Px, Py, Out)` | —— | 关于直线镜像 |
| `vector_angle_to_rigid (Row1, Col1, Ang1, Row2, Col2, Ang2, Out)` | 全为控制参数 | **点 + 角度对应 → 刚体矩阵**，最常用 |
| `vector_to_rigid` / `vector_to_similarity` / `vector_to_aniso` / `vector_to_hom_mat2d` | —— | 多组对应点反求矩阵（能力依次变强） |
| `hom_mat2d_invert (HomMat2D, Out)` | —— | 求逆（正变换 ↔ 反变换） |
| `hom_mat2d_to_affine_par (HomMat2D, Sx, Sy, Phi, Theta, Tx, Ty)` | 6 个输出 | **反解**变换参数 |

> [!tip] 叠加顺序
> `hom_mat2d_*` 是**左乘**：**代码里先写的操作，先作用在对象上**。
> 因此后面操作里的固定点 `(Px, Py)` 要写"**前面几步搬完之后**"的位置 —— 写"原始位置"就会跑偏。

### 9.2 用出去

| 算子 | 对象 | 控制参数 |
|---|---|---|
| `affine_trans_image (Image, Out : HM, Interpolation, AdaptImageSize)` | Image | 插值 `'nearest_neighbor'`/`'bilinear'`/`'constant'`(默认)/`'weighted'`/`'bicubic'`；尺寸 `'true'`/`'false'`（默认） |
| `affine_trans_region (Region, Out : HM, Interpolate)` | Region | `'nearest_neighbor'`(默认) / `'constant'` |
| `affine_trans_contour_xld (Contours, Out : HM)` | XLD 轮廓 | 无 |
| `affine_trans_polygon_xld (Polygons, Out : HM)` | XLD 多边形 | 无 |
| `affine_trans_pixel (HM, Row, Col, RowT, ColT)` | 点，**像素坐标系** | 传参 `(Row, Col)` |
| `affine_trans_point_2d (HM, Px, Py, Qx, Qy)` | 点，**标准坐标系** | 传参 `(Px, Py)` = `(Col, Row)` |

> [!warning] 三条容易踩的
> ① `affine_trans_image` **忽略输入图像的 domain**（当作整幅矩形），且**左、上边界永远会被裁掉**；
> ② `affine_trans_image` / `affine_trans_region` 用的是**像素坐标系**（原点在左上角像素外角），和 `area_center` 返回的标准坐标系差 **0.5 像素**；
> ③ `hom_mat2d_to_affine_par` 只认官方的拼装顺序 `scale → slant → rotate → translate`，顺序不同就反解不回原参数。

> [!note] 顺带记住这几个
> - `gen_contour_region_xld (Regions : Contours : Mode)`，`Mode` = `'border'`（默认）/ `'center'` / `'border_holes'`
> - `area_center_xld (XLD : : : Area, Row, Column, PointOrder)`，比区域版多一个绕行方向
> - `orientation_xld (XLD : : : Phi)`
> - `reduce_domain (Image, Region : ImageReduced)` —— 矩阵尺寸**不变**
> - `crop_domain (Image : ImagePart)` —— 矩阵裁到 domain 的最小外接矩形
> - `full_domain (Image : ImageFull)` —— 把 domain 扩回整块矩形
